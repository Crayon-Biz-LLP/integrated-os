# Common English words — the bounded authority for the residue-gate
# derivation filter (M17 hardened fix, 2026-08-17).
#
# WHY THIS FILE EXISTS
# --------------------
# The residue gate derives blocklist tokens from tenant data (users.name,
# person_aliases, user_settings.domains / personal_orgs). Tenant-authored
# area/domain names are frequently ORDINARY English words ("Errands",
# "Work", "Groceries") — and such words legitimately appear in shared code
# (UI copy, presets, prompts). A scan hit on an ordinary word is NOT
# evidence of a leak, exactly like the STOPLIST's stated purpose.
#
# This list is the BOUNDED authority for that judgment: any DERIVED token
# whose lowercase form is here is dropped at derivation time, before it ever
# becomes a blocklist token. It is intentionally a *common-word* list —
# English's ordinary vocabulary does not grow with the tenant count, so this
# stays small and stable no matter how many tenants join.
#
# NOT in this list: proper nouns (names, orgs, domains, URLs) — those stay
# in the static supplement and are never filtered. If a tenant's distinctive
# org name is also an ordinary word (the "Apple" gap), this filter cannot
# resolve the ambiguity — that residual is closed by the data-driven
# invariant (all tenant-visible strings come from DB rows), not by this list.
#
# Keeping this list tight matters: every word here is a free pass. Only add
# words that are genuinely ordinary English and plausibly usable as a
# tenant area/domain name.
#
# Categories below are organizational only — the loader reads every line.
